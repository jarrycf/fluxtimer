# fluxtimer

[English](README.md) · 中文

作者：jarrycf · 版本：4.3.0 · Obsidian 桌面端

参考 Flux Timer 的紧凑计时交互，固定在当前笔记内容区顶部居中。倒计时可同时运行；正向计时共用单任务后台，支持横排与竖排；控件跟随 Obsidian 的浅色 / 深色主题。

## 更新与使用

在 Obsidian 第三方插件中关闭再开启 fluxtimer，加载新版。

- 点击「＋」，默认选择排在前面的正向计时，也可切换倒计时。
- 倒计时：输入分钟或分:秒，例如 `25` / `00:30`，按 Enter 或点击输入条末尾的「＋」开始。也可向右拖动末尾「＋」，松手开始。
- 正向计时：填写提醒事项后点击 ▷，从零开始。点击圆环可暂停、继续或结束；暂停不计入用时。点「结束」即写入记录并把该圆环从轨道移除，不再弹出提醒卡片。
- 倒计时结束后可追加 1 / 5 / 30 分钟，或重新开始。提前取消不记录。提醒卡片只属于倒计时。
- 右键主「＋」切换横竖布局，或打开任务历史、统计面板及导出。
- 命令面板中搜索「fluxtimer」：新增计时器 / 倒计时 / 正向计时、暂停或继续最近的计时、关闭所有到时提醒、切换排列、打开日志与统计。命令不带默认快捷键，可在 Obsidian 快捷键设置中自行绑定。
- 点击圆环展开详情：大号剩余 / 已用时间、进度条、预计结束时刻；倒计时可 +1 / +5 分钟或重新开始。
- 底部状态栏显示最近到时的倒计时（切到非笔记视图也能看到），点击可展开该计时器；可在设置中关闭。
- 倒计时结束且 Obsidian 不在前台时弹出系统通知（可关闭）。
- 「＋」面板记住上次选择的模式。
- 点击插件控件之外的任何位置（笔记正文、侧边栏、其他窗格、Obsidian 菜单）会自动收起已展开的计时器详情面板。这次点击照常生效、焦点不被抢走；「＋」新增面板不受影响，需用 × 或 Esc 关闭，避免误丢已输入的时长与名称。

## 显示设置

「显示大小」滑块范围为 20–48 像素，默认 24。只调整圆环和主「＋」，设置页内的两个示例以及笔记中的控件同步变化。输入面板和完成提醒采用独立的紧凑尺寸。旧存档里仍是旧默认值 28 的会在重载时一次性迁移为 24；手动调到其他数值后不再被覆盖。

## Markdown 用时记录

首次加载默认创建根目录 `提示事项.md`，已有文件不会覆盖。可在插件设置中选择其他已有 Markdown 文档。

只有在提醒事项中填写了内容的计时才记录。点击内置预设时，如果没有填写提醒内容，则不写入文档。倒计时到时写入；正向计时开始时创建未完成任务，结束时勾选并补上用时。启动另一项正向计时会停止上一项的计时，保留已累计用时。提前取消不写入完成记录，已有外部任务历史保留。暂停时间扣除；分钟数四舍五入，少于 30 秒显示 0 分钟。

按结束日期归档。一天的第一条记录生成日期行；下一个记录日第一次写入时，才补齐上一记录日的累计。累计取文档该日期下各条记录的整数分钟之和。倒计时到时后追加时长，追加段完成时另写一条；正在运行时延长则并入本次记录。

示例：

```md
9.20
- [x] 数学回顾:公式 250分钟
- [x] 408回顾: 错题 750分钟
- [x] 9.20累计用时: 1000分钟

9.21
- [x] 数学25年真题一轮 24分钟
```

每条新记录使用 Task Time Tracker 的 `[tt-id:: 唯一编号]` 标记，关联任务与计时历史并避免重复写入；显示方式可在任务计时设置中选择。旧 HTML 标记仍可识别，但不再生成。记录失败时保留待写入内容，可在设置中点击「重试写入」。绑定现有文档时会在末尾继续追加，不清空原文；建议使用专门的记录文档。

计时与设置保存在插件 data.json，旧版活动计时自动迁移。Obsidian 关闭期间不能发声；重新打开后倒计时按原结束时间恢复，正向计时继续累计墙钟时间（如需停止累计请先暂停）。任务同步会在仓库中查找相同任务编号；不发起网络请求。

## 更新日志

### 4.3.0

- 中英文切换：设置最上方「语言 / Language」可选 中文 / English / 跟随 Obsidian（默认中文）。覆盖计时控件、设置页、通知、状态栏、命令名称，以及内置 Task Time Tracker 的日志、统计、导出和弹窗（如启动时的「有未结束的计时」）。切换即时生效；命令面板里的命令名称需重新加载插件后更新。
- 内置 Task Time Tracker 原本只有英文 / 西班牙文；新增 205 条中文翻译（`i18n.cjs` 的 `TTT_ZH`），由 `build.cjs` 在打包时注入语言开关，不修改 `vendor/` 原文件。若将来更换 vendor 版本导致注入点失效，构建会直接报错。
- 未自定义的快捷预设跟随语言（休息一下 / Short break）；4.2 存下的默认中文预设视为未自定义。
- 写入笔记的记录格式（「N分钟」「累计用时」）不随语言变化，以免破坏已有记录的累计。

### 4.2.0

- 外观重做：浅色主题为「磨砂白纸」、深色主题为「烟灰石墨」，控件跟随 Obsidian 主题切换，不再固定深色。原先叠在一起的四层样式（含追加在 Task Time Tracker 样式之后、强制白色输入文字的 `!important` 块）合并为一层，以 CSS 变量区分两套主题。
- 颜色语义统一：倒计时蓝、正向计时青绿、暂停琥珀、到时珊瑚红；圆环、详情徽标、进度条和提醒卡片共用同一套颜色。圆环保持透明、正向计时仍只显示分钟数。
- 新增面板改为一张卡片：模式分段控件 + 预计结束时间同一行，预设改为胶囊标签横排；开始按钮为实色。
- 详情面板：大号时间、进度条、「共 xx:xx · hh:mm 结束」，倒计时新增 +1 分钟与重新开始。
- 新增：可自定义快捷预设（设置 →「快捷预设」，如 `休息一下=5, 番茄专注=25, 冥想=00:30`，最多 6 个）、状态栏倒计时、系统通知、命令面板命令、记住上次模式。设置页预览同时展示四种状态。

### 4.1.0

- 顶部更紧凑：控件顶边距内容区顶部由约 13px 收到 2px（`top: 10px` + 轨道 3px 内边距 → `top: 2px` + 轨道不再有纵向内边距）。
- 主「＋」去掉外框：不再有边框、底色和背景模糊，和左侧圆环一样完全透明；只在悬停时出现极淡的圆形反馈，键盘聚焦保留细描边。
- 「＋」颜色改为跟随圆环（浅色 `#6685ad`、深色 `#c1d8fa`），不再写死 `#7a94b5`；字形比例由 0.48×尺寸放大到 0.52×尺寸，去掉外框后依然清晰。
- 默认显示大小由 28px 改为 24px；旧存档里仍是 28 的值会一次性迁移为 24（存档写入 `version: 4`），之后手动调到 28 不再被覆盖。滑块范围仍为 20–48。
- 圆环名称气泡修好并改到图标下方：原先气泡挂在圆环内部，被轨道的滚动容器裁掉（纵向只剩 3px 内边距可见；横向溢出还会在轨道底部撑出一根灰色滚动条）。现在气泡挂在根节点、在悬停或键盘聚焦时按圆环位置定位，单行省略显示，并随计时实时刷新。轨道保留滚动能力，只是不再显示滚动条（`scrollbar-width: none` 与 `::-webkit-scrollbar`）。
- 圆环按钮不再写原生 `title`，避免系统提示与本插件气泡叠在一起（`aria-label` 保留，读屏提示不受影响）。
- 新增点击外部自动收起：在控件之外任意位置按下指针即收起已展开的计时器详情面板（捕获阶段监听 `pointerdown`，覆盖笔记正文、侧边栏、其他窗格与原生菜单）。这次点击不被拦截、焦点也不交给「＋」；「＋」新增面板故意豁免，保留已输入内容。原有的三条收起路径（详情面板「−」、新增面板「×」、Esc）行为不变。
- 正向计时改为“结束即收工”，不再出现“已计时 N 分钟”提醒卡片：`act()` 里 `await this.bridge.finish(timer)` 之后立刻调用 `retireFinishedUp()` 把该圆环从轨道移除（记录与任务后台写入都在 `bridge.finish()` 内部完成，不会丢）。同一条规则覆盖另外两条结束路径——笔记里勾掉任务触发的后台结束会在下一个 `tick()`（200ms）里移除，加载存档时也会丢掉停留在“已完成”的正向计时。提醒卡片现在只由倒计时触发（`renderFinished()` 只渲染 `mode === 'down'`），倒计时的 +1 / +5 / +30 分钟与重新开始保持不变。副作用：正向计时结束后不再有「↻ 重新开始同一任务」入口，需要继续计时请点「＋」新建。

## Task Time Tracker 合并

保留原 0.0.31 的任务行播放/停止、历史记录编辑与删除、项目及客户管理、统计面板、CSV/Toggl/Clockify 导出和任务编号显示设置。完整设置位于 fluxtimer 设置中的任务计时区域。正向圆环与任务行使用同一后台，任一入口暂停或继续都会同步。

首次加载时，若存在原 Task Time Tracker 的数据，会备份并复制到本插件目录的 `tracker-migration-backup.json` 与 `tracker-data.json`；没有则从空数据开始。若原插件仍在启用，会弹出提示请你手动停用，以免重复计时；本插件不会自动停用其他插件，也不删除原插件文件。之后的计时存入 fluxtimer 的 `tracker-data.json`，不回写旧插件。

顶部主「＋」无外框、无底色、无背景模糊，与圆环一样全透明，仅悬停时出现极淡圆形反馈；加号、关闭和播放按钮使用居中 SVG；输入框聚焦时保持深色透明背景和浅色文字。圆环名称气泡显示在图标下方，悬停或键盘聚焦时按圆环位置定位。

原模块及许可说明见 `vendor/NOTICE.md`。修改 `main.source.js`、`i18n.cjs` 或 `tracker-bridge.cjs` 后运行 `node build.cjs` 生成 `main.js`。
